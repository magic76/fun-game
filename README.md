# Fun Game · 小玩具實驗室

公開的純靜態互動小玩具集合，不需後端或安裝。

## 入口
- 首頁：https://magic76.github.io/fun-game/
- 轉盤畫室：https://magic76.github.io/fun-game/spin-art/

## 開發與部署
每個小玩具放在自己的目錄，例如 `spin-art/index.html`。
GitHub Actions 只把首頁及目前支援的玩具複製到 `_site`，再部署 GitHub Pages。
不再執行舊 3D 辦公室遊戲的測試、Python 套件安裝或 GLB 模型產生。

Pages 設定：Settings → Pages → Source 選 GitHub Actions。

## 舊版
原本的「薪水小偷俱樂部」3D 辦公室遊戲已退役，不再作為首頁或 Pages 部署內容。歷史程式檔暫留 Git 版本紀錄與工作樹，方便後續清理；不會發布到網站。
